Important summary:

- WebPad++ is a local-first browser toolbox.
- It does not use a project-owned backend for user document processing.
- The default web build may still load third-party resources such as analytics, Tailwind runtime, CDN fallbacks, and OCR language data.
- An offline release requires bundled vendor files, local OCR language data, disabled analytics, and a network-panel review.
